# 鸠占鹊巢·记忆核心（NTR MemoryCore）

一个 SillyTavern 自定义扩展：把「剧情记忆」搬出 AI 的大脑存进本地，并在每次生成前智能注入回上下文。解决 deepseek 长对话里的数值丢失、前后文对不上、多线切换错乱。

---

## 一键安装（推荐，手机 / 电脑 / 云酒馆通用）

1. 打开酒馆 → 顶部 **Extensions（拼图/方块图标）** → 点 **Install Extension（云朵下载图标）**；
2. 粘贴本仓库地址：

   ```
(https://github.com/huaixvliang/ntr-memory)
   ```

3. 点 **Install**，等它下载完成；
4. **刷新页面**（Ctrl+F5 或手机下拉刷新）；
5. 再进 Extensions 设置区，能看到 **「鸠占鹊巢·记忆核心」** 面板即成功。

> 手机端无需碰文件系统：手机浏览器打开酒馆 → 同样点 Extensions → Install Extension → 粘贴地址 → 安装 → 刷新。前提是部署酒馆的宿主（云服务器 / Termux）已安装 git。

## 手动安装（备选）

把本仓库的 `manifest.json` 和 `index.js` 两个文件放进：

```
SillyTavern/public/scripts/extensions/ntr-memory/
```

刷新酒馆即可。

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动总结 | 每 N 条消息（默认 5，可调）用主 API 提取「标签/人物/数值/时间/地点/事件」 |
| 分层归档 | 数值快照（固定）+ 事件时间线（滚动 15 条）+ 阶段摘要（10 段）+ 总纲 |
| 生成前注入 | 每次生成前把「世界观 + 数值快照 + 时间线 + 摘要」注入，总量稳定不膨胀 |
| 常驻世界观 | 每次注入优先带世界观，历史被截断也不丢基础设定 |
| 改记忆 | 可视化面板直接改数值 / 删时间线 / 改摘要（AI 提取不保证 100% 对） |
| 调总结楼层 | 面板里把「每 5 条一总结」改成 3 / 10 / 任意层 |

## 斜杠命令

| 命令 | 作用 |
| --- | --- |
| `/mem` | 查看记忆状态 + 数值快照 |
| `/mem-set 人物 字段 值` | 改数值，如 `/mem-set 沈清璃 好感 80`（字段：好感/沉沦/背德/暴露/服从/发现） |
| `/mem-rm 人物` | 删除某人快照 |
| `/mem-sum` | 立即总结待处理消息 |
| `/mem-clear` | 清空全部记忆 |

## 可调参数（设置面板里直接改）

- **总结楼层** `queueSize`（默认 5）：每几条消息总结一次；
- **时间线保留** `timelineMax`（默认 15）：时间线留几条事件；
- **摘要间隔** `summaryEvery`（默认 15）：每几条事件压一段摘要；
- **摘要段数** `summaryMax`（默认 10）：阶段摘要保留几段。

## 注意事项

- 总结调用你的**主 API**（`generateRaw` 后台生成，不显示在聊天里），会多花一点 token；嫌频繁就把 `queueSize` 调大。
- 总结失败会自动跳过，不打断正常对话。
- 记忆存进酒馆 `extension_settings`，换会话不丢；换酒馆实例需重新开始。

## 故障排查

| 现象 | 排查 |
| --- | --- |
| 扩展列表里看不到 | 一键安装后记得**刷新页面**；手动安装要确认层级是 `extensions/ntr-memory/` 下直接是这两个文件 |
| 不总结 | API 没连接；或按 F12 看控制台 `[ntr-memory]` 日志 |
| 总结乱码/没效果 | 主 API 输出 JSON 失败会自动跳过，属正常容错，不影响主对话 |
| 想彻底停用 | 扩展列表取消勾选，或 `/mem-clear` 清空 |
